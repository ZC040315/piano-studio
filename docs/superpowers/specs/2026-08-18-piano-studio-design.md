# Piano Studio — 零基础钢琴自学网站 设计文档

日期：2026-08-18
状态：已获用户确认

## 1. 背景与目标

为无基础的钢琴自学者构建一个「边学边练」的独立学习网站「Piano Studio」：以结构化图文课程为主线，每课内置可交互的跟练键盘，让零基础用户从认识键盘一路学到能弹简单流行歌的左手和弦伴奏。

成功标准：
- 零基础用户打开即能开始第一课，无需任何乐理前置知识。
- 每课形成完整练习闭环：讲解 → 跟练 → 完成打卡。
- 跟练模式有即时反馈：按对前进、按错温和提示，像游戏一样有成就感。
- 进度保存在浏览器本地，无需登录，打开即用。
- 纯静态构建，可部署到任何静态托管，桌面与移动端体验完整。

## 2. 范围（已确认）

### 2.1 功能范围
- 首页：品牌区 + 三阶段学习路径总览 + 「继续学习」推荐（按本地进度定位下一未学课程）。
- 课程页：按阶段分组的课程卡片列表，显示标题、要点与完成状态。
- 课程详情页：图文讲解 + 动画演示 + 音频示例 + 跟练练习区 + 完成打卡。
- 学习指南页：坐姿手型、练琴习惯、识谱速查表、常见问题。
- 跟练模式：简谱显示、键盘高亮提示、按对前进、演示模式、得分与星级。
- 进度：localStorage 保存已学课程与练习星级。

不在本期范围（后续可加）：账号与云同步、自由弹奏练琴房、真人视频课程、MIDI/录音、社区与排行榜。

### 2.2 课程体系（24 课 / 3 阶段）

阶段一 认识与入门（1–8 课）：
1. 认识钢琴与键盘：白键黑键、do re mi 位置
2. 坐姿与手型（动画演示）
3. 手指编号与单手练习
4. 简谱入门：音名、唱名、数字谱
5. 时值基础：全音符 / 二分 / 四分 / 八分音符
6. 小节与拍号、打拍子
7. 节奏练习（含节拍器演示）
8. 曲目：《小星星》前半段

阶段二 基础与双手（9–16 课）：
9. C 大调音阶（上行 / 下行）
10. 双手交替与协调
11. 《小星星》完整版
12. 《两只老虎》
13. 《欢乐颂》
14. 附点音符与休止符
15. 反复记号与常见记谱符号
16. 综合复习小曲

阶段三 和弦与伴奏（17–24 课）：
17. 三和弦入门：C / G / Am / F（动画演示）
18. 柱式和弦伴奏型
19. 分解和弦伴奏型
20. 左右手配合：旋律 + 和弦
21. 伴奏节奏型变化
22. 弹唱入门：伴奏型 + 简单唱谱
23. 结业曲目（简化简谱，如《月亮代表我的心》）
24. 综合复习与进阶路线建议

每课固定结构：学习目标 → 图文/动画讲解 → 小节跟练 → 综合跟练曲 → 完成打卡。
练习数量按阶段配置：阶段一每课 2–3 个短练习；阶段二每课 2 个短练习 + 1 个综合曲；阶段三每课 1–2 个短练习 + 1 个综合曲。

### 2.3 曲目库
- 公版经典：小星星、两只老虎、欢乐颂、小蜜蜂、致爱丽丝（简化）、卡农（简化）。
- 流行彩蛋：第 23 课结业曲目确定为《月亮代表我的心》（简化简谱，标注「简化改编」）；若用户公开部署有顾虑可随时替换。

### 2.4 跟练模式设计
- 虚拟键盘：中央 C 附近约 1.5–2 个八度，白键黑键完整，木色琴键样式，可鼠标点击。
- 电脑键盘映射：`A S D F G H J` = do re mi fa sol la si；黑键 `W E T Y U`；练习区聚焦时拦截按键，避免页面滚动冲突。
- 简谱显示：练习进行中当前音符高亮；键盘高亮下一个要按的键。
- 按键反馈：按对播放对应音并前进；按错温和提示并允许重试。
- 演示模式：自动按节奏播放整段旋律，供先听后练。
- 练习结束：显示得分与三星制星级，写入本地进度。
- 音频：Web Audio API 合成钢琴音色（基音 + 泛音 + 指数衰减包络），不依赖音频文件。

### 3.2 字体与排版
- 标题：Noto Serif SC 衬线（600–700 字重），营造书本般的安静感。
- 正文：Noto Sans SC 无衬线（400）。
- 层级：H1 约 34–40px、区块标题 20–24px、正文 15–16px、辅助 13px。
- 行距 1.7，适合长文阅读。

### 3.3 布局与组件
- 顶部导航：logo（钢琴图标 + 站点名）+ 导航（首页 / 课程 / 学习指南）+ 进度概览。
- 首页：温暖 hero（简洁插画/渐变）→ 三阶段路径卡片 → 「继续学习」横幅 → 新手须知。
- 课程页：按阶段分组的课程卡片（编号、标题、要点、完成勾）。
- 课程详情：讲解区（图文 + 动画）在上，练习区（简谱 + 键盘 + 控制条）在下或侧栏。
- 学习指南：卡片式速查表 + 文章式说明。
- 动效：克制的淡入、键盘高亮呼吸效果、完成打卡打勾动画；尊重 `prefers-reduced-motion`。

## 4. 信息架构与路由

单页应用（React Router）：
- `/` 首页
- `/lessons` 课程列表
- `/lessons/:id` 课程详情
- `/guide` 学习指南
- 未知路由显示 404 页，含「返回首页」入口。

## 5. 技术架构

### 5.1 技术栈
- React 18 + Vite + React Router DOM（与现有 STORMCAP 同栈，但为独立项目目录 `piano-studio/`，互不影响）。
- 纯前端静态站点：Web Audio API 合成音色、localStorage 进度。
- 原生 CSS + 设计令牌变量（tokens.css）。

### 5.2 目录结构（规划）
```
piano-studio/
  index.html
  package.json / vite.config.js
  src/
    main.jsx / App.jsx
    styles/   tokens.css / global.css / components.css / pages.css
    data/     lessons.js（24 课内容）/ exercises.js（跟练练习数据）
    lib/      notes.js（简谱解析与频率计算）/ audio.js（钢琴音色）/ progress.js（进度读写）
    components/  Header / Footer / Piano / Practice / SheetDisplay / AnimatedDemo / ProgressBadge ...
    pages/    HomePage / LessonsPage / LessonPage / GuidePage
```

### 5.3 数据流
1. 路由 → 页面组件从 `data/` 读取对应课程与练习数据（纯静态模块）。
2. Practice 组件解析练习数据为音符序列 `[{note, beats}]`，构建「目标序列 + 当前索引」状态。
3. 用户按键/点击 → 与当前目标音比对：正确则 `audio.play(note)` 并前进；错误则提示并保持。
4. 练习完成 → `progress.save(courseId, stars)` → 界面更新进度徽标。
5. 首页「继续学习」读取进度，定位第一门未完成课程。

### 5.4 错误处理
- Web Audio 不可用或受浏览器自动播放策略阻止：在用户首次与键盘交互时初始化 AudioContext；如失败显示提示，练习仍可进行（静音）。
- localStorage 不可用（如隐私模式）：降级为内存进度，页面提示「进度不会被保存」。
- 课程顺序：允许自由访问，不强制按序解锁，但首页与课程页会推荐按序学习。
- 键盘事件冲突：仅练习区激活时拦截按键输入，其余页面不受影响。

## 6. 测试与验收

1. 单元测试：简谱解析（音高/时值）、音符频率计算、进度存储读写。
2. 构建检查：`npm run build` 通过，无控制台错误。
3. 浏览器走查：桌面 + 移动端；核心链路 首页 → 课程 → 跟练（按键/点击/演示/得分）→ 进度 → 完成打卡闭环。
4. 无障碍：全键盘可操作、焦点可见、对比度达标、`prefers-reduced-motion` 生效。
