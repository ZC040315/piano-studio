# Piano Studio · 零基础钢琴自学网站

为完全没有乐理基础的自学者设计的「边学边练」网站：24 课图文课程，每课内置可交互的跟练键盘（简谱 + 高亮提示 + 演示模式 + 星级进度）。

## 功能

- **三阶段 24 课**：认识与入门（1–8）→ 基础与双手（9–16）→ 和弦与伴奏（17–24），从认识键盘到能弹简单流行歌伴奏。
- **跟练模式**：虚拟钢琴键盘可点击，也支持电脑键盘 `A S D F G H J K`（黑键 `W E T Y U`）；当前音符高亮、下一个键高亮，按对前进、按错提示；支持「演示」自动播放。
- **本地进度**：完成练习与课程后自动保存到浏览器 localStorage，无需登录；首页「继续学习」自动定位下一课。
- **纯静态**：构建后为纯静态文件，可部署到 GitHub Pages / Vercel / Netlify 等任意静态托管。

## 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:5173 。

## 构建与测试

```bash
npm test       # 单元测试（简谱解析 / 进度存储 / 跟练状态机 / 数据完整性）
npm run build  # 产物在 dist/
```

## 目录结构

```
src/
  lib/          # 简谱解析、频率、音频合成、进度存储、跟练状态机、琴键映射
  data/         # 24 课课程内容与跟练练习数据
  components/   # 键盘 / 简谱 / 跟练 / 动画演示 / 导航等组件
  pages/        # 首页 / 课程列表 / 课程详情 / 学习指南
  styles/       # 设计令牌与组件、页面样式
```

## 简谱写法（本站约定）

- `1 2 3 4 5 6 7`：do re mi fa sol la si，默认一拍。
- `1-`：延长一拍（两拍）；`1---` 四拍。
- `1_`：半拍（八分音符）。
- `1.`：附点（一拍半）。
- `0`：休止符（不发声）。
- `1'`：高八度；`1,` 低八度。
- `[135]`：和弦（三个音一起按）。

## 曲目与版权说明

- 曲库以公版经典旋律为主（小星星、两只老虎、欢乐颂、小蜜蜂等）。
- 第 23 课《月亮代表我的心》为简化改编版本，仅供学习参考；如需公开部署，可自行替换该课练习数据（`src/data/exercises.js` 中 `lesson-23-ex1`）。

## 部署

构建产物 `dist/` 使用相对资源路径，直接上传任意静态托管即可。
