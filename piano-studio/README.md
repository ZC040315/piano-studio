# Piano Studio · 零基础钢琴自学网站

为完全没有乐理基础的自学者设计的「边学边练」网站：24 课图文课程，每课内置可交互的跟练键盘（简谱 + 高亮提示 + 演示模式 + 星级进度），并配有 B 站教学视频与 30 首曲目的曲谱库。

## 功能

- **三阶段 24 课**：认识与入门（1–8）→ 基础与双手（9–16）→ 和弦与伴奏（17–24），从认识键盘到能弹简单流行歌伴奏。
- **跟练模式**：虚拟钢琴键盘可点击，也支持电脑键盘 `A S D F G H J K`（黑键 `W E T Y U`）；当前音符高亮、下一个键高亮，按对前进、按错提示；支持「演示」自动播放。
- **每课教学视频**：课程详情页内嵌 B 站公开免费教程，先看示范再跟练；暂未配齐的课程显示「视频待补充」占位。
- **曲谱库**：30 首流行歌曲与钢琴纯音乐简谱（含虫儿飞、茉莉花、月亮代表我的心、卡农、致爱丽丝、天空之城等），支持分类筛选、难度星级，可直接复用跟练组件弹奏；未校对曲目显示「待校对」徽标。
- **本地进度**：完成练习与课程后自动保存到浏览器 localStorage，无需登录；首页「继续学习」自动定位下一课。
- **纯静态**：构建后为纯静态文件，可部署到 GitHub Pages / Vercel / Netlify 等任意静态托管。

## 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:5173 。

## 构建与测试

```bash
npm test       # 单元测试（简谱解析 / 进度存储 / 跟练状态机 / 数据完整性）
npm run build  # 产物在 dist/
```

## 目录结构

```
src/
  lib/          # 简谱解析、频率、音频合成、进度存储、跟练状态机、琴键映射
  data/         # 24 课课程内容、跟练练习数据与曲谱库数据
  components/   # 键盘 / 简谱 / 跟练 / 视频 / 动画演示 / 导航等组件
  pages/        # 首页 / 课程列表 / 课程详情 / 曲谱库 / 学习指南
  styles/       # 设计令牌与组件、页面样式
```

## 简谱写法（本站约定）

- `1 2 3 4 5 6 7`：do re mi fa sol la si，默认一拍。
- `1-`：延长一拍（两拍）；`1---` 四拍。
- `1_`：半拍（八分音符）。
- `1.`：附点（一拍半）。
- `0`：休止符（不发声）。
- `1'`：高八度；`1,` 低八度。
- `[135]`：和弦（三个音一起按）。
- `2#`：升号（# 写在数字后，如 `2#`=升 do）；`b7`：降号（写在数字前，如 `b7`=降 si）。
